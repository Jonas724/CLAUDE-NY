# Sektion 9 — Kvalitetsgrindar (alla = JA innan publicering)

> Misslyckad grind → åtgärda → kör om HELA listan. Max 3 varv, sedan eskalera med loggen.

## Paketering
- [ ] Thumbnail läsbar på 120×68 px
- [ ] Titel ≤ 55 tecken med exakt en klickmekanism
- [ ] Titel + thumbnail lovar något videon levererar inom 60 sek

## Innehåll
- [ ] Hook levererar titelns löfte inom 15 sek
- [ ] Ingen sträcka >90 sek utan mönsterbrott
- [ ] Alla öppnade loopar stängda
- [ ] Alla fakta/siffror verifierade mot minst en källa (loggad)
- [ ] 0 % återanvänt/oredigerat tredjepartsmaterial; alla tillgångar licensloggade

## Teknik
- [ ] Ljud −14 LUFS, ingen klippning, musik under rösten
- [ ] Inga AI-artefakter i bild (extra fingrar, smält text)
- [ ] Undertexter verifierade (namn, siffror, termer)
- [ ] Inget visuellt dödläge >7 sek

## Policy
- [ ] Klarar annonsvänlighetsriktlinjerna
- [ ] AI-genererat realistiskt innehåll markerat enligt YouTubes disclosure-krav
- [ ] Metadata komplett: beskrivning, kapitel, taggar, spellista, slutskärm, kort
